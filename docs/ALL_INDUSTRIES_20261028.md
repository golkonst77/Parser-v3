## Строительство: новый отдельный сбор

```powershell
Set-Location -LiteralPath 'D:\DATA\Parser V2_0'
$run = '.\local_run\construction_1000_20261028'
New-Item -ItemType Directory -Path $run -Force | Out-Null
python -B -u .\parser_run.py --industry 3 --target 1000 --max-cards 10000 --max-pages 200 --database "$run\data.db" --output "$run\sample.csv" 2>&1 | Tee-Object -FilePath "$run\run.log"
```

Этот путь должен быть новым. Если БД уже существует, используйте продолжение:

```powershell
Set-Location -LiteralPath 'D:\DATA\Parser V2_0'
$run = '.\local_run\construction_1000_20261028'
python -B -u .\parser_run.py --industry 3 --target 1000 --resume --max-cards 10000 --max-pages 200 --database "$run\data.db" --output "$run\sample.csv" 2>&1 | Tee-Object -FilePath "$run\resume.log" -Append
```

В режиме --resume target означает итог отрасли, ранее обработанные карточки
пропускаются до загрузки, CSV заново формируется из накопленных пригодных записей
данной БД без дублей. Для сохранения прежнего снимка CSV перед продолжением его
можно скопировать; база сохраняет накопленные записи. Старые базы строительства
с конфигурацией search_queries безопасно возобновить автоматически нельзя:
resume_state отклоняет такой запуск; сохраните их отдельно и используйте новую БД.
Новые рубрики красоты и других отраслей могут менять порядок карточек на стороне
источника; пропуск обработанных URL сохраняется, гарантии полного покрытия нет.
