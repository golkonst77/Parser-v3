конфигурация рейтинга и действующий .gitignore. Все 8 отраслей ready; только
медицина — MedAdvisor. Остальные — отдельные общероссийские рубрики Orgpage,
включая стоматологию. Меню и CLI теперь используют живой медицинский каталог.
Наличие medadvisor.csv не требуется штатному целевому потоку.

N без resume — новые пригодные организации, с resume — итог отрасли.
CSV накопительный, SQLite хранит решения и проверки. Явная БД другой отрасли
отклоняется. Resume пропускает обработанные карточки, но Orgpage заново читает
страницы каталога с начала. Подробные ограничения — [RUNBOOK](RUNBOOK.md).
Защита сайта допускается только при подтверждённой странице защиты, скрининг
unknown; TLS не отключён. Госфильтр старой конфигурации не применяется в
целевом Collection-пути: исключение всех госучреждений не гарантировано.
